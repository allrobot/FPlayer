# 抖音式播放交互规格

## 1. 设计基调

这是工作型本地播放器，不复制抖音品牌。播放画面全屏、控件紧凑、层级靠透明度和位置建立：黑色底、白/灰主控、青色作为设备/脚本状态、红色只用于点踩/断连/危险停止。文本不使用随视口缩放的字号，字间距为 0。

所有图标按钮视觉尺寸 32~40 dp、触摸热区至少 48 x 48 dp；常驻面板圆角不超过 8 dp。页面区段不做浮动卡片，设置项是一行一个操作。图标有 content description，陌生图标长按/悬停环境提供说明。

## 2. 屏幕拓扑

### 播放 Feed

- 视频占满可用 viewport，底部导航覆盖黑色稳定区域，不随媒体比例改变。
- 顶部透明工具带含七个逻辑控制：抽屉、SMB、本地、收藏、推荐、搜索、更多/来源管理。
- SMB/本地/收藏/推荐表现为紧凑来源 tabs；窄屏允许横向滚动，但抽屉、搜索和当前 tab 始终可见。
- 右侧竖栏依次为文件夹头像、喜欢、收藏、点踩；计数为空时不保留无意义占位文字。
- 左下信息最多三行：文件名、文件夹、时长/分辨率/帧率摘要；长词中间省略且不遮挡右栏。
- 进度/热力图贴近底部导航上缘，几何高度固定，状态改变不推动其他控件。

### 底部导航

- 首页、相册、设备、设置四项；高度和选中指示稳定。
- 从某文件夹网格进入播放后，首次点首页回到该网格上下文；再次点首页回到默认 Feed。状态必须可见地反映当前上下文，避免像按钮失效。

### 网格/双列

- 单屏网格默认 3 列（平板按最小 tile 宽自适应），tile 固定 3:2 或由阶段原型验证后的单一比例。
- 双列模式使用更大封面和两行元数据；两种布局不共享会导致跳动的动态高度。
- 当前/刚看过 tile 叠加半透明中性色和“刚刚看过”，底部微进度条不改变 tile 高度。

## 3. Feed 垂直分页状态机

状态：`Idle -> Tracking -> DirectionLocked -> Settling -> Active`。

- `Tracking` 在触点移动超过系统 touch slop 后开始。
- 当 `abs(dy) >= 1.25 * abs(dx)` 锁为纵向；当 `abs(dx) >= 1.25 * abs(dy)` 锁为横向。锁定后本手势不切方向。
- 释放时，位移达到页面高度 18% 或同方向速度达到 1100 dp/s，任一成立就翻页。
- 速度触发仍要求至少 24 dp 有效移动，过滤抖动/误触。
- 未达阈值回弹当前项，不允许停在半屏。
- 只有吸附到目标页 95% 以上并 settle 完成后，目标项才成为唯一 Active 播放器和脚本源。
- 快速连续滑动可跳队列索引，但任一时刻只有一个媒体实例输出音频/设备命令。
- 到达顺序边界时只做短距离阻尼和一次轻触觉反馈，不循环索引；媒体自身循环与 Feed 循环是不同设置。

## 4. 点击、横滑、长按冲突

优先级：进度拖动 > 系统边缘返回 > 已锁定 Feed 滑动 > 边缘临时倍速 > 普通长按 > 单击。

### 单击

- 按下到抬起不超过 220 ms，移动不超过 touch slop，且未被子控件消费时切换播放/暂停。
- 点击按钮/进度条不向视频背景冒泡。
- 切换后中心播放图标短暂淡入淡出，不长期遮挡内容。

### 横滑进入网格

- 不在进度热区或系统返回边缘起手；方向锁为横向。
- 向左位移达到宽度 20% 或速度达到 1100 dp/s 且移动至少 24 dp 时进入当前 scope 网格。
- 未达阈值回弹，不与“水平拖动进度”共用同一触摸区域。

### 普通长按播放设置

- 中央 60% 视频区域保持 500 ms、移动不超过 12 dp 后触发。
- 触发时中等触觉反馈一次；竖屏从底部进入约半屏，横屏从右侧进入约半屏。
- 一旦纵/横滑动锁定或进度拖动开始，取消长按计时。

### 屏幕边缘临时倍速

- 左/右各 20% 视频区域保持 350 ms 后临时切到用户配置倍速，默认 2x；松手立即恢复原速度。
- 激活后显示小型速度标识，不弹播放设置。
- 从系统返回手势边缘开始时系统手势优先；可在设置关闭此功能。
- 该功能在 T25 阶段实现，普通长按先完成也不能占用边缘区域。

## 5. 进度条和 Funscript 热力图

普通进度条与热力图共享同一个 `ProgressInteractionState`，只替换轨道渲染：

| 状态 | 视觉 | 交互 |
| --- | --- | --- |
| Playing | 1 dp 半透明轨道；短视频可延迟弱化 | 热区仍保持 48 dp，不显示 knob |
| Paused | 2 dp 轨道和清晰已播放段 | 可直接点按 seek |
| Pressed | 轨道过渡到 4 dp | 锁定手势，隐藏非必要叠层 |
| Dragging | 4 dp 轨道、12 dp knob、时间浮层 | 连续预览，节流提交 seek |
| Settling | knob 回落、等待播放器确认 | 忽略过期 position 回调 |

- 热力图用时间 x 轴和 pos/密度/速度组合呈现，不把曲线高度当作真实视频布局高度。
- 多轴默认合成概览，设置可选单轴；颜色需能在色觉缺陷下通过明度/线型区分。
- 拖动时间浮层显示 `当前 / 总时长`，不遮住手指和底部导航。
- 到 0%/100% 各提供一次触觉反馈；停在端点不重复震动。
- 拖动仅更新预览位置；松手提交最终 seek，脚本调度增加 generation 并从确认媒体时钟恢复。

## 6. 播放设置面板

面板是一列紧凑行，不使用卡片套卡片：播放排序、跳转视频、倍速、屏幕旋转、静音、字幕、清屏、软/硬解、长宽比、自动连播、自定义播放设置、热力图开关、更多。

- 影响范围在副标题中明确为“当前视频”“当前来源”或“全部视频”。
- 排序立即生成新顺序但保持当前视频；完成前显示行内进度，不阻塞面板。
- 倍速为非循环横向滚轮，0.1x~5x；中央选中值固定宽度，边缘渐隐。
- 旋转使用互斥选项：竖屏向上/向下、横屏向左/向右、自动旋转；不允许组合成矛盾状态。
- 静音是应用级布尔状态，不修改系统媒体音量；系统音量为零时 UI 显示“系统静音”来源。
- 字幕默认自动同名，可选无字幕或 SAF 选择覆盖；覆盖只作用当前媒体，除非用户另存规则。
- 解码模式切换需要重新准备时给出短暂状态，失败自动回退并显示原因。

## 7. 清屏模式

隐藏顶部工具带、右侧操作、左下信息和底部主导航，只保留底部四个稳定控件：退出清屏、后退 5 秒、播放/暂停、倍速。

- 四控件使用图标；倍速显示当前倍率作为必要状态文字。
- 倍速单击按 `0.25x -> 0.5x -> 1x -> 2x -> 3x -> 5x` 循环。
- 清屏仍保留系统返回可退出；进度拖动可通过点击底部安全区域临时唤出。
- 设备断连/急停属于安全状态，必须覆盖清屏并可见，不能因“清屏”隐藏。

## 8. 自定义播放设置

- 上区为已选，下区为未选，中间固定分隔；每项一行。
- 已选项使用移除图标，未选项使用添加图标；不依赖仅颜色表达。
- 拖动时显示全宽插入线；接近列表上/下边缘时速度分级自动滚动。
- 拖动不会改变行高，放下后才持久化；取消/旋转恢复最近已提交顺序。
- 提供无障碍“上移/下移/添加/移除”动作，不能只有拖拽路径。

## 9. 横屏和平板

- 横屏播放设置是右侧面板，宽度取 `min(50% viewport, 480 dp)`；视频区域不被控件永久挤压。
- 平板 Feed 仍以单一 active 视频为中心，不因宽屏把多个视频同时自动播放。
- 顶/底控件使用 window insets；任何文字和按钮不可与打孔、状态栏、导航栏或系统手势区重叠。
- 大屏不放大字号填空白，通过较宽信息栏、稳定控件间距和网格列数利用空间。

## 10. 可访问性与验收

- 动态文字在系统字体 1.3x 下不与按钮重叠；更大字号允许行高增长而非裁剪命令文字。
- 所有状态变化同时有图形/文字或 content description，不只靠颜色。
- 动效遵循“减少动态效果”；分页吸附保留但缩短非必要淡入。
- UI 阶段必须在至少手机竖/横屏、目标平板竖/横屏四个 viewport 做截图和触摸自动化。
- 对 Feed、进度、长按和清屏分别建立状态机测试，不用一个端到端测试覆盖全部冲突。

## 11. 外部观察依据

- 抖音现行交互公开资料和搜索结果确认：长按菜单包含倍速/清屏类入口，边缘长按可用于临时倍速；不同版本存在 A/B 差异，因此本规格固定自身状态机而不追随私有实现。
- 进度条交互参考公开的移动视频进度设计原则：[优设进度条设计分析](https://www.uisdc.com/progress-bar-design-2)
