# Funscript 热力图降采样

本文固定 P2/T06 的数据边界。`ScriptHeatmapDownsampler` 只生成 UI 可视化数据，不参与
设备限幅、调度或安全决策。

## 窗口模型

- 调用方提供闭区间 `HeatmapWindow(startMs, endMs)` 和每轴最大样本数。
- 样本预算至少为 4，输出严格不超过 `maxSamplesPerAxis`。
- 每次缩放或水平拖动都按新窗口重新查询；算法通过二分查找定位窗口动作，不复制整条
  轨道，额外内存为 `O(maxSamplesPerAxis)`。
- 窗口首尾总是生成精确时间点。边界没有原 action 时使用 T05 的线性插值，因此相邻
  窗口共享同一个时间/位置边界，拖动时不会漂移。

## 极值保留

动作数超过预算时，按时间宽度均匀分桶。每桶最多输出四个按原始时间排序且去重的点：

1. 首个点；
2. 最小位置点；
3. 最大位置点；
4. 末个点。

因此单个瞬时尖峰或深谷不会被平均值抹除，首末趋势也保持连续。动作数未超过预算时
返回窗口内全部原始点和两个插值边界，不做近似。

## 多轴与调用约束

多轴按 `AxisId.value` 排序，每轴独立应用相同预算，避免动作密集轴挤占其他轴。输入必须
来自 T04 已严格校验、时间戳递增的 `ScriptBundle`。Compose 控件只消费
`ScriptHeatmap`；颜色、线型和多轴合成规则在 T24 实现，不能反向改变本算法的时间点。
